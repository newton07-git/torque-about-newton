Grid independence in a 2D convection problem

CFD model verification · Academic project

Compared five mesh sizes and three flow models to assess consistency in the outlet temperature profile of a 2D convection problem.

5Mesh element sizes
3Flow models compared

Engineering question

How fine does the mesh need to be for the outlet temperature profile to stop changing meaningfully?

My contribution

  • Compared five mesh element sizes in a 2D convection problem.
  • Extracted temperature profiles along a vertical line at the channel outlet.
  • Compared laminar, standard k–ω, and k–ε flow models through temperature contours and line profiles.

Purpose

Used mesh convergence to balance numerical consistency against unnecessary computational cost.
